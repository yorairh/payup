# PayUp — future plans (from testers)

Built one by one; each gets its clarifying questions first.

1. [x] **Pencil icon on player cards.** The table's player card gets a small pencil next to the name so people know tapping it opens the buy-in list (edit / delete / remove player).
2. [x] **Chips mode: no money text box.** With chip counting on, show each player's chips worth as money text (read-only) instead of a second field. Auto-fill of the last blank player should work on the chips field the same way it does for money.
3. [x] **Result screen: tap a player for details.** Opens everything about that player: net, who they pay or receive from, and their buy-ins (how much they put in). Not added to the share feature.
4. [x] **Random dealer on New game.** A toggle (off by default). When on, starting the game shows a screen that deals random cards to the players; the first player to get an ace is the dealer (who starts).
5. [x] **App language in Settings.** English, Hebrew, Spanish, Russian, Arabic, French, German, Portuguese, Chinese (Simplified), plus "System default" (the default). Uses Android per-app locales.
6. [x] **Currency on New game.** Choose ₪ $ € £ ₽ ¥ when starting a game; saved per game (old games stay ₪), defaults to the last one used. Symbol only, no conversion. Leaderboard adds amounts and shows the latest game's currency. Built after item 5.
