# PayUp 0.4.0

**New**
- **PayUp on the web:** the same app now runs in the browser at https://payup-ae6fc.web.app (now https://payup.web.app). On iPhone (iOS 18.2 or newer), open it in Safari and use Share → Add to Home Screen to install it. Games are saved on that device only.
- **Move games between devices:** Settings → Backup creates a file, and Restore on the web or on Android reads it.
- The app version now shows in the bottom left corner of the home screen.

**Under the hood**
- The code is now shared between Android and the web. This includes a new database engine (Room 3) and a new navigation library. Your saved games carry over.

`PayUp-0.4.0.apk` is attached. It installs over 0.2.0.
